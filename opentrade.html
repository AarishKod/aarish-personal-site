UI Bug

Dark Mode: Invisible Source Text

While exploring OpenTrade's AI research feature, I noticed that after the agent performs research and displays the sources it found, the source text is rendered in a very dark shade of black. Against the dark mode background, this text is essentially invisible.

What's going on

Expected

Source text should render in white or a light color in dark mode, matching the rest of the UI's text hierarchy.

Actual

Source text uses a dark black color that blends into the dark background, making it unreadable.

This is likely a missing color override for the dark theme. The source text probably inherits a default light-mode color (dark text) that doesn't get swapped when the dark theme is active. A fix as simple as setting the source text color to var(--text) or #f6f4ef in the dark theme stylesheet should resolve it.

Users rely on source attribution to trust AI-generated insights. If they can't see where the information came from, it undermines confidence in the product — which is otherwise genuinely impressive.
